# Kid Games 🎮

Free browser games for kids. No downloads, no ads, and no build step. Each game is a folder with a single `index.html`.

**Play:** https://mlcassara-ai.github.io/kid-games/

## Games
- [Lake Legends](lake-legends/): a San Diego lake fishing game with a Fishdex and boss fish (ages 8–12).
- [Math Quest](math-quest/): a monster-battling math adventure for addition, subtraction, multiplication and division, with pets, a shop and a parent corner (ages 7–12).
- [Molecule Lab](https://mlcassara-ai.github.io/molecule-lab/): molecule science games (in its own repository).

## Adding a game
1. Make a new folder, for example `my-game/`, with the game's `index.html` inside.
2. Add a card for it in the top-level `index.html`.
